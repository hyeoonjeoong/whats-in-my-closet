# /task-done - 계획 완료 처리

완료된 계획 문서를 '완료' 폴더로 이동합니다.

## 사용법

```
/task-done [기능명 또는 파일명]
```

인자 없이 실행하면 현재 진행 중인 계획 목록을 보여줍니다.

## 실행 내용

1. `.claude/plans/` 에서 해당 계획 문서 찾기
2. 문서 내 모든 체크리스트가 완료되었는지 확인
3. 상태를 "완료"로 변경하고 완료일 추가
4. `.claude/plans/완료/` 폴더로 이동

## 완료 처리 시 문서 변경

```markdown
# [기능명]

- 생성일: YYYY-MM-DD
- 완료일: YYYY-MM-DD     ← 추가
- 상태: 완료              ← 변경
```

## 주의사항

- 체크리스트에 미완료 항목이 있으면 경고 표시
- 강제 완료 옵션: `/task-done [기능명] --force`
- 이미 완료 폴더에 있는 문서는 처리하지 않음
