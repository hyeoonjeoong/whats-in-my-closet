# /task - 작업 계획 생성

새로운 기능 개발을 위한 계획 문서를 생성합니다.

## 사용법

```
/task [기능명]
```

## 실행 내용

1. `.claude/plans/` 폴더에 계획 문서 생성
2. 파일명: `YYYY-MM-DD-기능명.md`
3. 체크리스트 형식의 템플릿 포함

## 템플릿

다음 형식으로 계획 문서를 생성하세요:

```markdown
# [기능명]

- 생성일: YYYY-MM-DD
- 상태: 진행 중

## 개요

[기능에 대한 간단한 설명]

## 체크리스트

- [ ] 요구사항 분석
- [ ] 구현 계획 수립
- [ ] 코드 구현
- [ ] 테스트
- [ ] 코드 리뷰/정리

## 상세 작업

### 1. [세부 작업 1]
- [ ] 항목 1
- [ ] 항목 2

### 2. [세부 작업 2]
- [ ] 항목 1
- [ ] 항목 2

## 관련 파일

- `path/to/file1.ts`
- `path/to/file2.tsx`

## 메모

[작업 중 메모 사항]
```

## 주의사항

- 기능명은 한글 또는 영문 모두 가능
- 기존 동일 이름의 계획이 있으면 덮어쓰지 않고 알림
