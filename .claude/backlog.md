# Backlog (기능 백로그)

구현 예정인 기능들의 러프한 아이디어를 정리합니다.
구체적인 구현 계획이 정해지면 `.claude/plans/`에 별도 문서로 작성합니다.

---

## 진행 중

### 룩북 기능
- 실제 착용 사진 업로드
- 착용 아이템 태그 (옷장 아이템 연결)
- 날짜/장소 기록 가능

---

## 예정

### 코디 즐겨찾기
- 코디 탭에서 즐겨찾기 기능
- 자주 입는 코디 빠르게 접근
- 즐겨찾기 필터링

### 코디 그룹 (컬렉션)
- 코디를 그룹별로 묶어서 관리
- 사용 예시:
  - "여름 여행 코디"
  - "3박4일 겨울 여행"
  - "출근룩 모음"
  - "데이트룩"
- 그룹 생성/편집/삭제
- 코디를 여러 그룹에 추가 가능 (다대다 관계)

### 로그인 기능
- 소셜 로그인 (Google, Kakao 등)
- Supabase Auth 활용
- 현재 비밀번호 방식 → 로그인 방식으로 전환

### 마이페이지
- 프로필 관리
- 선호 사이즈 설정

### 선호 사이즈 관리
- 카테고리별 선호 사이즈 기록
- 예시:
  - 크롭티: S사이즈, 총장 45cm 선호
  - 오버핏 맨투맨: L사이즈, 어깨 60cm 선호
  - 청바지: 28인치, 하이웨스트 선호
- 실제 보유 옷과 연동
  - "이 옷의 핏이 딱 좋아" 마킹
  - 해당 옷의 실측 사이즈 참고
- 온라인 쇼핑 시 사이즈 참고용

## 아이디어 (검토 필요)

> 우선순위나 구현 여부가 정해지지 않은 아이디어

- 옷 착용 횟수 트래킹
- 계절별 코디 추천

- 옷 처분 관리 (안 입는 옷 정리)
